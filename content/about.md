I'm a machine learning engineer on a graduate scheme in banking: first data engineering, now ML
engineering. My work is AI agents on Google Cloud, and how to tell whether they're right.

**What I care about:** taking a messy real problem, building an agent that solves it end to end,
shipping it, and proving it works with a number instead of a demo.

**How I work:**
- Ship small and fast, then improve. Real users matter more than polish.
- Every project has evals: did the agent get the right answer, and did it take the right path?
- I write up findings ("I measured X and found Y"), not diaries.

**Certifications:** Google Cloud Professional Machine Learning Engineer (2026).

Everything here uses public data.
